---
name: branching
description: Branch hygiene basics — branch off the default branch for non-trivial work, give branches meaningful names that reference the bug/feature or issue number, run tests before merging, squash commits before merging. User-invoked study aid.
disable-model-invocation: true
---

- for any non-trivial functionality, work in a branch
- create a branch off main (this repo's default branch)
- give the branch a meaningful name that references the bug or feature you are working on
- if the functionality is covered in a repository issue, the branch name should contain the issue number
- run tests before attempting to merge
- squash commits before merging
