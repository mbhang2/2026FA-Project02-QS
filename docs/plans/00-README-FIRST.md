# Plan README

This directory holds implementation plans written as markdown files (or quarto markdown if they need executable code).

**These Plans are Artifacts for finished, contemplated, or in process work, they are not authoritative for current capabilities**

Current implementation should be **expected** to drift from the plans over time, older plans are more likely to have been revised or modified. Authoritative, maintained, documentation should exist in ADRS, runbooks, `make help`, and other final documentation targets.  When in doubt, read the code.
